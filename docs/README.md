# TribeInn V1 Website Asset Pack — V2

Definitive curated image package for the first TribeInn website build.

## Included
- The Beginning: living room, bedroom, kitchen, utility/laundry, bathroom and practical images.
- Prepared desktop/mobile homepage hero crops.
- Rio De Goa: colourful buildings/courtyard, landscaping, gym, terrace seating, central courtyard, common lounge source image and terrace/water view.
- Goa destination image.
- Selected original masters.
- `IMAGE-GUIDE.md` with usage and truthfulness rules.
- `image-manifest.csv` mapping source files to web assets.

## Production notes
Web assets are WebP and have only restrained resizing/contrast/sharpness adjustments. The property has not been AI-redesigned.

The rooftop infinity pool is intentionally excluded from the production story because it is not available to TribeInn guests.
